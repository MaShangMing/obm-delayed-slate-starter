# 延迟反馈下的预算约束上下文组合决策

本任务研究带延迟半反馈的上下文组合决策。每个独立实例有900轮，6类动作，每轮只出现其中4至6类且每类至多一个候选。每轮预算和互斥组重新给出，不存在跨轮累计花费约束。候选收益为相互独立的0或1随机变量，其概率由动作类别、3维上下文及上下文交互决定；概率在0.03至0.97之间，可保持稳定、发生一次未知时点的突变或平滑变化。反馈延迟与收益独立，取0至30轮；长延迟场景仍遵循相同接口和范围。实例名称、分布类别、生成种子、真实概率、未选动作收益和未来候选均不提供给运行中的策略。只可修改并提交environment/policy.py，整个文件可改；其他起始文件不可修改。实现Policy(config)，以及choose(observation)返回本轮所选候选id字符串列表。每个实例新建进程和Policy对象，允许保留该实例内的内存状态。config恰含arms=6、features=3、horizon=900、seed=0；seed是可供策略使用的固定随机种子，不是数据生成种子。observation恰含round、budget、slots、offers、feedback。round为从0递增的整数，budget为3至7的整数，slots为2或3。offers是候选对象列表，每项恰含id、arm、x、cost、group；id是本轮唯一不透明字符串，不承载收益信息；arm是0至5的整数；x为3个有限实数且各分量在负1至1之间；cost为1至4的整数；group为0至3的整数。候选顺序不表示收益排序。所选id必须来自本轮offers且不得重复，数量不超过slots，cost之和不超过budget，同一group最多选一个；预算恰好用尽合法，空列表始终合法，列表顺序不计分。feedback是本轮开始前到达的已选动作反馈列表，每项恰含id、arm、x、decision_round、reward，前三项来自当时所选候选，decision_round是当时轮号，reward为0或1整数。选择发生在轮t的动作，在t+1+delay轮开始前到达；每个已选动作反馈至多一次，同轮反馈可与决策顺序不同。空反馈不表示奖励为零；900轮结束后才到达的反馈不再交给策略，但对应动作的期望收益仍计入成绩。不得读取未到达反馈、候选之外的真实概率或评测文件；这些资料不会挂载到候选进程。从environment运行python3 -B run.py < ../eval_dev/protocol.jsonl可检查协议；运行python3 -B selftest.py --data ../eval_dev/episodes.json --limit 12可评估开发集。run.py使用UTF-8逐行JSON，第一条请求为type=reset及config，响应恰为ready=true；随后每条请求为type=step及observation，响应恰含chosen。choose返回列表，由固定run.py封装；不得向标准输出写调试文本，单条输出至多65536字节。输入保证合法，不考察无效请求处理。采用Linux、Python3.11及以上标准库、单CPU核、2GB地址空间，不提供GPU或网络；运行需要系统bubblewrap支持用户命名空间。评测只把policy.py和固定run.py放入只读/app，提供Python运行时、独立/proc、/dev和空白/tmp；不挂载开发答案、完整proposal、隐藏数据、评分脚本或参考实现。不得启动外部子进程或利用文件、环境变量、网络获取非协议信息。只使用Python标准库；策略结构、学习方法、参数和随机化由解题者自行选择。每次协议响应最长5秒，每个实例进程累计CPU时间45秒、总墙钟60秒。开发集和隐藏集各12个实例，每组3个数据种子各生成稳定、突变、渐变、长延迟4类场景，每实例900轮；两组使用相同参数与数据生成分布，隐藏组更换系数、上下文、候选标识、预算、互斥组、反馈延迟和奖励抽样。开发文件含完整概率、预抽样奖励、延迟及逐轮最优期望收益，可用于离线研究，但在线自测和正式评测仅通过相同观测协议交互。所有数据为本题合成，不宣称来自实际投放记录。对每轮，裁判在已知真实收益概率时枚举合法组合，求该轮最大期望收益v；候选组合期望收益为u。单实例遗憾率R为所有轮的v减u之和除以所有轮的v之和。每类场景先对3个种子的R等权平均；mean_regret为4类平均，worst_regret为4类最大值，L=0.75*mean_regret+0.25*worst_regret。分数为max(0,min(1,1-L/0.17007739303812774))。L=0是逐轮最优的数学上锚点，下锚点0.17007739303812774来自随包无上下文基线在隐藏集的实测，不等于要求策略达到完美信息最优。参考质量线分别为mean_regret不超过0.09且worst_regret不超过0.12，仅报告是否达到，不额外清零。任一实例输出格式错误、非法组合、异常退出、输出超限或超过任一公开运行时限，整题得0分；修改非可改文件同样整题得0分。候选收益由裁判重算，不使用候选自报分数。开发预算2小时，构建检查上限60秒，整套评分预算15分钟；仅做版本、隔离工具与文件检查，无需下载或编译依赖。
